# @dxgjs/fs

Filesystem abstraction layer for DXG.

> Internal package of the [DXG](https://github.com/dxgjs/dxg) monorepo. If you want to use DXG, install the CLI instead: `npx @dxgjs/cli`.

## Installation

```bash
npm i @dxgjs/fs
# or
pnpm add @dxgjs/fs
```

## Requirements

- Node.js >= 22.13
- ESM only

## Entry points

- `@dxgjs/fs` – filesystem abstraction used by the DXG generators
- `@dxgjs/fs/testing` – in-memory filesystem for tests, mirroring the `@dxgjs/fs` API
