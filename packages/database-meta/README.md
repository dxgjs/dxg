# @dxgjs/database-meta

Shared database metadata for DXG: supported providers, recommended scripts and path conventions.

> Internal package of the [DXG](https://github.com/dxgjs/dxg) monorepo. If you want to use DXG, install the CLI instead: `npx @dxgjs/cli`.

## Installation

```bash
npm i @dxgjs/database-meta
# or
pnpm add @dxgjs/database-meta
```

## Requirements

- Node.js >= 22.13
- ESM only
