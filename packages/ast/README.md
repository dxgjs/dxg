# @dxgjs/ast

AST manipulation utilities powered by Magicast for preserving formatting, comments, and structure when modifying config files.

> Internal package of the [DXG](https://github.com/dxgjs/dxg) monorepo. If you want to use DXG, install the CLI instead: `npx @dxgjs/cli`.

## Installation

```bash
npm i @dxgjs/ast
# or
pnpm add @dxgjs/ast
```

## Requirements

- Node.js >= 22.13
- ESM only

## Entry points

- `@dxgjs/ast` – main entry point
- `@dxgjs/ast/json` – JSON/JS/TS config file manipulation (preserves formatting, comments and key order)
- `@dxgjs/ast/ts-injection` – TypeScript/JavaScript source injection helpers (imports, config files)
