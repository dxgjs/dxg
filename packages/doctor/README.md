# @dxgjs/doctor

Diagnostic and repair tool for DXG projects.

> Internal package of the [DXG](https://github.com/dxgjs/dxg) monorepo. If you want to use DXG, install the CLI instead: `npx @dxgjs/cli`.

## Installation

```bash
npm i @dxgjs/doctor
# or
pnpm add @dxgjs/doctor
```

## Requirements

- Node.js >= 22.13
- ESM only
