# @dxgjs/templates

Template engine for DXG.

> Internal package of the [DXG](https://github.com/dxgjs/dxg) monorepo. If you want to use DXG, install the CLI instead: `npx @dxgjs/cli`.

## Installation

```bash
npm i @dxgjs/templates
# or
pnpm add @dxgjs/templates
```

## Requirements

- Node.js >= 22.13
- ESM only
